# ⛅ Weatherly - თანამედროვე Weather App (React)

მინიმალისტური, მუქი ლურჯი დიზაინის მქონე ამინდის აპლიკაცია, შექმნილი **React**-ზე.

---

## 🚀 გაშვების ინსტრუქცია

პროექტის გასაშვებად ტერმინალში გაუშვით შემდეგი ბრძანება:

```bash
npm run dev
```

შემდეგ ბრაუზერში გახსენით: [http://localhost:5173](http://localhost:5173)

---

## 🌟 ძირითადი ფუნქციები

1. **ქალაქის ძებნა**:
   - ნებისმიერი ქალაქის მოძებნა საძიებო ველის მეშვეობით.
   - პოპულარული ქალაქების სწრაფი არჩევანი (თბილისი, ბათუმი, ქუთაისი, London, Paris, New York, Tokyo).
2. **მიმდინარე ამინდი**:
   - ტემპერატურა (°C).
   - ამინდის მდგომარეობა (მაგ. მზიანი, წვიმიანი, ღრუბლიანი) და შესაბამისი ანიმირებული იკონი.
   - შეიგრძნობა როგორც (Feels like).
3. **დამატებითი მეტრიკები**:
   - 💧 ტენიანობა (Humidity - %).
   - 💨 ქარის სიჩქარე (Wind speed - კმ/სთ).
   - 🧭 ატმოსფერული წნევა (Pressure - hPa).
4. **5-დღიანი პროგნოზი**:
   - თითოეული დღის მაქსიმალური და მინიმალური ტემპერატურა.
   - ამინდის აღწერა, იკონკა და ნალექის ალბათობა.

## 📁 პროექტის სტრუქტურა

```
src/
├── components/
│   ├── Header.jsx           # სათაური, ლოგო და მიმდინარე თარიღი
│   ├── SearchBar.jsx        # საძიებო ველი და პოპულარული ქალაქების ღილაკები
│   ├── CurrentWeather.jsx   # მიმდინარე ამინდის ძირითადი ბარათი
│   ├── WeatherDetails.jsx   # ტენიანობის, ქარისა და წნევის ბარათები
│   ├── Forecast.jsx         # 5-დღიანი პროგნოზის კონტეინერი (map)
│   └── ForecastCard.jsx     # ერთი დღის პროგნოზის ცალკეული ბარათი
├── data/
│   └── weatherData.js       # საწყისი/სარეზერვო მონაცემები
├── services/
│   └── weatherService.js    # მონაცემების მიღება რეალური API-დან (Open-Meteo) და სარეზერვო ლოგიკა
├── App.jsx                  # მთავარი კომპონენტი (useState, useEffect, Props)
├── App.css                  # მუქი ლურჯი მინიმალისტური სტილები
├── index.css                # გლობალური საბაზისო CSS
└── main.jsx                 # React root render
```

## 💡 გამოყენებული React კონცეფციები

- **კომპონენტები (Components)**: თითოეული ელემენტი გატანილია ცალკე `.jsx` ფაილში.
- **Props**: მშობელი კომპონენტიდან (`App.jsx`) მონაცემებისა და ფუნქციების გადაცემა შვილ კომპონენტებზე.
- **useState**: ქალაქის, ამინდის მონაცემების, ჩატვირთვის (`loading`) და შეცდომის (`error`) მდგომარეობების სამართავად.
- **useEffect**: ქალაქის შეცვლისას ამინდის მონაცემების ავტომატური წამოღებისა და განახლებისთვის.
- **მასივები და map()**: 5-დღიანი პროგნოზის, მეტრიკებისა და პოპულარული ქალაქების დინამიური ასახვისთვის.
- **სუფთა CSS**: არ არის გამოყენებული გარე ზედმეტი ბიბლიოთეკები; დაცულია მუქი ლურჯი, თანამედროვე და მინიმალისტური სტილი.
